# Anonymous Complaint Box

## Student side

- Students open `/student/complaint` from the Student Dashboard.
- They select a category and submit a subject and complaint.
- The application does not store the student's ID, name, email, department, or account reference with the complaint.

## Super Admin side

- Only the Super Admin can open `/admin/complaints`.
- Complaints can be filtered and marked as New, Reviewing, Resolved, or Dismissed.
- The Super Admin can add a private review note or delete a complaint.

## Library dashboard

- The Library admin is redirected to `/library/dashboard` after login.
- This dashboard contains only Manage Library and Manage Notices.
